# Rowmoss — Keep your row

A focused knitting and crochet row counter by **Sepideh Javanbakht Dalir**.

**Status: in production; not submitted or released.** Universal iPhone and iPad, iOS15+. Commercial source is private.

![Rowmoss counted-loop icon](docs/assets/icon.png)

Rowmoss keeps completed rows and the next row in a named repeat together, with persistent undo and an inspectable saved position. One useful project is free. A one-time Lifetime Pro purchase adds a project library, reusable repeat patterns and history. No subscription, account, ads or tracking.

The engineering work focuses on explicit repeat semantics, serialized actions, atomic local persistence, integrity validation, previous-generation recovery and undo after reset/relaunch. SwiftUI adapts to a dedicated iPad work basket. StoreKit2 verifies purchase entitlements; existing projects remain accessible after entitlement changes. Foundation and CryptoKit handle storage. XCTest and StoreKitTest cover core integrity and transaction states; remote sandbox/release evidence is still pending.

The product is a bounded market experiment in an established category. No invented exclusivity or demand claim. Final UI and marketing campaign will be added after visual QA.
